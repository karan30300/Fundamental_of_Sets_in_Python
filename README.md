##🧠 Topics Demonstrated

The script covers the following set concepts:

Creating a set with multiple data types

Automatic removal of duplicate values

Checking set type and length

Difference between an empty dictionary {} and an empty set set()

Mutability of sets vs immutability of set elements

⚙ Set Properties Highlighted

Sets are unordered collections

Sets store unique elements only

Sets are mutable, but their elements must be immutable

Supported element types used:

Boolean

Integer

Float

String

Tuple

Mutable data types like list and dictionary are not allowed as set elements

🔧 Set Methods Used

The following built-in set methods are demonstrated:

add() — Add elements to a set

remove() — Remove a specific element

pop() — Remove a random element

clear() — Remove all elements from the set

union() — Combine elements of two sets into a new set

intersection() — Get common elements between two sets

▶ Execution

Run the script using:

python Set.py


🎯 Purpose

This project is intended for Python beginners to understand how sets work, how they handle uniqueness, and how basic set methods operate without using advanced concepts.

🧾 Conclusion

This script provides a clear and practical overview of Python set fundamentals, focusing on real usage and behavior of sets during execution.
